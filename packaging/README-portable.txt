ウマ娘 ファン数トラッカー(ポータブル版)

【使い方】
1. このフォルダを、書き込める場所(デスクトップ、ドキュメント、D: など)に置きます。
   Program Files など、書き込めない場所では起動できません。
2. FanTracker.exe をダブルクリックします。黒いウィンドウが開き、ブラウザで画面が表示されます。
   (表示されないときは、ウィンドウに表示された http://127.0.0.1:8000/ をブラウザで開いてください)
3. 使い終わったら、黒いウィンドウを閉じます(最小化して置いておいても構いません)。

【データの場所】
このフォルダの data\ に、記録(fantracker.db)、取り込んだ画像(images\)、ログ(logs\)が保存されます。
アプリは、これ以外の場所には何も書き込みません。

【引っ越し・バックアップ・更新】
- 引っ越し・バックアップ: フォルダごとコピーします(アプリを止めてから)。
- 更新: 新しいバージョンのフォルダを展開し、古いフォルダの data\ を、新しいフォルダへコピーします。
- 削除: フォルダを削除するだけです(レジストリなどには何も残りません)。

【読み取り位置を調整したいとき】
ゲームのアップデートでレイアウトが変わったら、data\layout.json を作って読み取り領域を書きます
(書いたキーだけが同梱の設定を上書きします)。例:
  {"fan_total": {"x0": 0.3403, "y0": 0.7998, "x1": 0.4308, "y1": 0.8195}}

【注意】
- 通信は 127.0.0.1(このPC内)だけです。画像やデータは外部に送信されません。
- Windows の警告(SmartScreen)が出た場合は「詳細情報」→「実行」で起動できます(署名していないため)。

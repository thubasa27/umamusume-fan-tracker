ウマ娘 ファン数トラッカー(ポータブル版)

【使い方】
1. このフォルダを、書き込める場所(デスクトップ、ドキュメント、D: など)に置きます。
   Program Files など、書き込めない場所では起動できません。
2. FanTracker.exe をダブルクリックします。専用のウィンドウで画面が開きます。
   (専用ウィンドウに必要な WebView2 が無い場合は、自動でブラウザに切り替わります。
    その場合は、画面右上の「終了」ボタンで終了します)
3. 使い終わったら、ウィンドウを閉じます。閉じると、アプリも終了します。
4. CSV やグラフ(PNG)の保存では、保存先を選ぶダイアログが出ます。

ブラウザで使いたいとき: FanTracker.exe のショートカットを作り、リンク先の末尾に ` --browser` を付けます。

【データの場所】
このフォルダの data\ に、記録(fantracker.db)、取り込んだ画像(images\)、ログ(logs\)が保存されます。
アプリは、これ以外の場所には何も書き込みません。

【引っ越し・バックアップ・更新】
- 引っ越し・バックアップ: フォルダごとコピーします(アプリを止めてから)。
- 更新: 新しいバージョンのフォルダを展開し、古いフォルダの data\ を、新しいフォルダへコピーします。
- 削除: フォルダを削除するだけです(レジストリなどには何も残りません)。

【読み取り位置を調整したいとき】
ゲームのアップデートでレイアウトが変わったら、data\layout.json を作って読み取り領域を書きます
(書いたキーだけが同梱の設定を上書きします)。例:
  {"fan_total": {"x0": 0.3403, "y0": 0.7998, "x1": 0.4308, "y1": 0.8195}}

【注意】
- 通信は 127.0.0.1(このPC内)だけです。画像やデータは外部に送信されません。
- 同じパソコンの他のユーザーや他のソフトが、あなたのデータを読めないように、起動のたびに作る合言葉(トークン)で守っています。
  アプリが開く画面(専用ウィンドウ、または自動で開くブラウザ)からだけ使えます。ブラウザのブックマークから開いても、
  「この画面からは使えません」と表示されます(アプリを起動し直すと、開き直されます)。
- data\images\ には、取り込んだスクリーンショットの全体が保存されます。data\ フォルダは、他の人に渡さないでください
  (バックアップは、自分用に保管してください)。
- 起動できないときは、エラーのメッセージが表示されます。詳しい記録は data\logs\fantracker.log にあります。
- 専用ウィンドウには WebView2 ランタイムが必要です(Windows 11 は標準で入っています)。
- Windows の警告(SmartScreen)が出た場合は「詳細情報」→「実行」で起動できます(署名していないため)。
